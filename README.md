# Los Cardales Refrigeración

Sitio web en HTML, CSS y JavaScript puros (sin React ni compilación).

## Ver el sitio en tu compu
Hacé doble clic en `index.html`.

## Agregar un trabajo a la galería
1. Copiá la foto dentro de `img/trabajos/`.
2. Abrí `js/trabajos.js`, copiá una línea de la lista, pegala al final y cambiá los datos (archivo, categoría y título).

## Publicar en GitHub Pages
1. Subí **el contenido** de esta carpeta a la raíz del repositorio (`index.html` tiene que quedar arriba de todo, no dentro de otra carpeta).
2. En GitHub: **Settings → Pages → Build and deployment**.
3. En *Source* elegí **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guardá.
4. A los 1–2 minutos el sitio queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
